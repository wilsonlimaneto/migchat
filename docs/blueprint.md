# **App Name**: Gemini Chat Dark

## Core Features:

- Chat Interface: Clean and intuitive chat interface with message bubbles.
- Gemini API Integration: Connect to the Gemini API to send user prompts and receive AI-generated responses. This includes prompt formatting and result parsing.
- Chat History Display: Display the chat history in chronological order, with clear differentiation between user and bot messages.
- Markdown Rendering: Markdown support is enabled, to ensure bot's message includes nicely-rendered elements.
- Error Handling: Implement error handling to gracefully manage potential issues with the Gemini API, such as network errors or invalid responses.
- Authentication: Hardcoded authentication with user 'mig' and password 'mig2025'.

## Style Guidelines:

- Background color: Dark charcoal (#333333) for a sophisticated and modern feel.
- Primary color: Brick Red (#B22222) for message bubbles of user messages
- Accent color: Light Lavender (#D0BFFF) for chatbot message bubbles.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a modern look, suitable for both headlines and body text.
- Use simple, outlined icons for actions like sending messages and clearing the chat.
- Ensure a responsive layout that adapts to different screen sizes (desktop, tablet, mobile).
- Subtle animations for loading indicators and message transitions to enhance user experience.
